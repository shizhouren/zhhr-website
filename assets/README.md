# assets 静态资源目录说明

## 收款二维码（上线前必做）

入会缴费弹窗会自动优先加载本目录下的收款码图片；图片不存在时显示临时占位样式。

只需将你的真实收款码保存为以下两个文件名放入本目录并提交，页面上即自动展示：

| 文件名 | 用途 |
| --- | --- |
| `qr-wechat.png` | 微信收款码（微信 → 我 → 服务 → 收付款 → 二维码收款 → 保存图片） |
| `qr-alipay.png` | 支付宝收款码（支付宝 → 收钱码 → 保存图片） |

> 提示：图片建议为正方形 PNG，尺寸 600×600 以上更清晰。
> 若暂不开通线上扫码收款，可不上传，页面会保持占位样式，用户会通过页面上展示的对公账户转账。
